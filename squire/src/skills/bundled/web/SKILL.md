# Web Skill

Search the web and fetch content from URLs.

## Capabilities

- Search the web for current information
- Fetch and read web page content
- Extract text from articles and documentation
- Follow links and navigate web content

## Tools Available

- `web_search` - Search the web for information
- `web_fetch` - Fetch content from a URL

## Usage

When the user:
- Asks about current events or news
- Needs information from a specific website
- Wants to research a topic
- Needs to check documentation online

## Best Practices

1. Verify URLs before fetching
2. Summarize long content for relevance
3. Cite sources when sharing information
4. Respect rate limits and terms of service

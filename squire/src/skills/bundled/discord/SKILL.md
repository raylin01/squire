# Discord Skill

Manage Discord channels and messages through SquireBot.

## Capabilities

- Send messages to channels
- Create and rename channels
- Set channel topics
- Create forum posts
- Manage channel permissions

## Tools Available

- `discord_send_message` - Send a message
- `discord_create_channel` - Create a new channel
- `discord_rename_channel` - Rename a channel
- `discord_set_topic` - Set channel topic

## Usage

When the user:
- Wants to post an update to Discord
- Needs to create a new channel
- Wants to organize Discord workspace
- Needs to communicate progress

## Best Practices

1. Use appropriate channel names
2. Format messages clearly
3. Use embeds for rich content
4. Ping users only when necessary
